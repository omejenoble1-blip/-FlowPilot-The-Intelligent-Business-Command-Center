# User guide

## Start

Create a local profile and workspace. Dark mode is enabled by default. The profile is stored in the current browser; it is not a server account.

## Manage records

Use the sidebar to open Projects, Tasks, Finance, Budgets, Goals, Team, Risks, and Automations. Use the New button to create a record. Open the eye icon to view details, the pencil to edit, and the trash icon to delete after confirmation.

## Workflow

Create a project, add tasks and link them to it, then move tasks through To Do, In Progress, Review, and Completed on the Kanban board. Record financial transactions and create budgets for matching expense categories. Goals use current and target values. Time tracking supports running timers and manual entries.

## Backups

Use Settings or Reports to download a JSON backup. Restoring replaces existing local records, so export a backup before importing. CSV export is available for supported record lists.

## Search and analytics

Global search looks through supported local records. Analytics and dashboard values are derived from stored records and remain empty when there is no data.
